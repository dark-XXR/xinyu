# 中文代码注释规范

## 必须注释的位置

- 文件开头：说明模块用途、主要调用方和安全边界。
- 复杂业务规则：套餐计费、次数扣减、发布门禁、状态转换和回滚。
- 外部接口签名：解释签名算法、时间戳、随机数和供应商差异。
- 隐私与安全处理：解释为何不能记录验证码、密钥、完整手机号或上游响应。
- 兼容逻辑：解释旧版本、降级路径或供应商特例存在的原因。

## 不建议的注释

- 不给赋值、循环、返回值等显而易见代码逐行写注释。
- 不写“这里调用接口”“这里判断条件”等没有额外信息的描述。
- 注释不能代替清晰的函数名、类型和测试。
- 自动生成文件不补手工注释，应修改契约或生成模板。

## 示例

```python
# 线上调用必须读取已发布快照。管理员保存草稿时不能改变正在服务的模型价格和路由。
snapshot = provider_version.snapshot
```
